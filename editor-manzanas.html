Cargando mapa…

Editor de manzanas · Centro Solano

Marcá cada manzana directamente sobre OpenStreetMap. La forma la dibujás vos siguiendo las calles reales; después le asignás territorio y letra.

Cómo usarlo: elegí T y letra → apretá el ícono de polígono del mapa → hacé clic en cada esquina de la manzana → doble clic/cerrá el polígono. Después queda guardada en este navegador.
Preparado. Elegí un territorio y una letra y dibujá una manzana.
Las marcas se guardan en localStorage. Exportá el JSON periódicamente para tener una copia de seguridad.
