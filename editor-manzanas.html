Cargando mapa…

Editor de manzanas · Centro Solano

Marcá cada manzana directamente sobre OpenStreetMap. La forma la dibujás vos siguiendo las calles reales; después podés cambiar territorio, letra o referencia en cualquier momento.

Cómo usarlo: elegí T y letra → apretá el ícono de polígono del mapa → hacé clic en cada esquina de la manzana → cerrá el polígono. Para corregir una ya creada, seleccionála en el mapa o en la lista y usá Editar seleccionada.
Preparado. Elegí un territorio y una letra y dibujá una manzana.
Las marcas se guardan en este navegador. Exportá el JSON periódicamente para tener una copia de seguridad.
