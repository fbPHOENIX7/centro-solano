# Estructura del proyecto

El proyecto separa tres responsabilidades:

- **Contenido:** `index.html`
- **Diseño:** `src/styles/app.css`
- **Comportamiento:** `src/scripts/app.js`

Las imágenes se guardan en `public/images/` y la documentación en `docs/`.

Esta separación busca que futuras modificaciones puedan hacerse sin tener que rehacer toda la aplicación.
