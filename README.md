# Centro Solano Territorios

Sitio web inicial para organizar y publicar información territorial de Centro Solano.

## Estructura

- `index.html`: pantalla principal.
- `src/styles/app.css`: estilos y diseño responsive.
- `src/scripts/app.js`: comportamiento del menú.
- `public/images/`: imágenes utilizadas por el sitio.
- `docs/`: documentación para mantenimiento y futuras ampliaciones.

## Objetivo inicial

La primera pantalla muestra la fecha, un menú superior y la información de **Salidas de esta semana**. La estructura queda preparada para incorporar posteriormente nuevas funciones sin mezclar contenido, diseño y comportamiento.
